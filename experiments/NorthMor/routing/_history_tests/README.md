# Archive des Tests Historiques de Routage HyMAP

Ce dossier conserve les premiers tests de faisabilite d'execution hors ligne du routeur HyMAP2 sous MPI (tests 1 pas et 5 jours sur janvier 2018 realises le 24 octobre 2026).

- `lis_hymap_opl_2018/` : Environnement complet du test 5 jours (job SLURM, configurations, logs d'execution, restart Noah-MP utilise).
