# Test d'Ensemble Open Loop : ENS_OPL_TEST_3days

* **But** : Tester la propagation d'un ensemble Open Loop (sans assimilation) sur 3 jours en 2018.
* **Période simulée** : 3 jours en 2018.
* **Membres d'ensemble** : 20 membres.
* **Statut** : **NON CONCLUANT**. L'analyse a révélé que la dispersion observée entre les membres était en réalité héritée du restart DA initial utilisé pour l'initialisation, et ne reflétait pas la dispersion pure induite par les perturbations météorologiques.
* **Note sur les chemins historiques** : Exécuté initialement sous `experiments/NorthMor/matrix_2016_2020/ENS_OPL_TEST_3days` puis reclassé dans `tests/`.
