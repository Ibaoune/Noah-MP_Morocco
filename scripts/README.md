# LIS/Noah-MP Post-Processing & Evaluation Framework

This directory contains the Python-based post-processing and evaluation framework designed to analyze and compare Noah-MP Open Loop (OPL) and Data Assimilation (DA) experiments. The framework is heavily inspired by evaluation strategies found in modern hydrological DA literature (e.g., Ahmed et al., 2024), focusing on spatial validation, internal water budget consistency, and DA diagnostic statistics.

## Directory Structure

*   `scripts/`: Contains all the Python modules for analyzing the LIS NetCDF outputs.
*   `figures/`: Destination directory where all generated plots, maps, and diagrams are saved.
*   `logs/`: Destination directory for SLURM output and error logs generated by the batch job.

## Processing Flow

The post-processing framework is built modularly. The scripts execute sequentially to perform the following flow:
1.  **Data Ingestion**: Parses LIS NetCDF history files (`LIS_HIST_*.d01.nc`) across specified date ranges for both the OPL and DA experiments.
2.  **Spatial Aggregation**: Applies the LDT domain landmask (`lis_input.d01_5km.nc`) to mask out ocean/invalid pixels and compute basin-averaged time series.
3.  **Metrics Calculation**: Computes anomalies, statistical metrics (Correlation, Bias, RMSE), and temporal standard deviations.
4.  **Visualization**: Generates high-quality, publication-ready figures using `matplotlib` and `seaborn` styles.

## The Scripts & What They Generate

### 1. `utils_eval.py`
A core utility module that provides shared functions to read LIS files, extract specific layers (e.g., for soil moisture profiles), compute basin averages, and calculate statistical metrics. It is imported by the other scripts.

### 2. `eval_water_budget.py`
Checks the physical consistency of the water cycle to ensure DA increments do not introduce unrealistic imbalances.
*   **Generates**:
    *   `budget_components.png`: Time-series of Precipitation, ET, Runoff, and Storage change (`dS/dt`).
    *   `budget_residual.png`: Residuals plot tracking the closure term (`P - E - R - dS/dt`).
    *   `runoff_partitioning.png`: Tracks the ratio of Surface Runoff vs. Total Runoff.
    *   `sm_profile_evolution.png`: Soil moisture variations across all four Noah-MP vertical layers.

### 3. `compare_opl_da.py`
Provides direct comparative diagnostics between the OPL and DA states across the Sebou basin.
*   **Generates**:
    *   `basin_time_series_compare.png`: Stacked time series comparisons of ET, Top Layer SM, and Surface Runoff.
    *   `diff_map_ET.png`, `diff_map_Runoff.png`, `diff_map_SM_top.png`: Spatial anomaly maps visualizing the mean difference (`DA - OPL`) across the 5km grid.

### 4. `eval_da_stats.py`
Evaluates the performance and behavior of the Ensemble Kalman Filter (EnKF) itself.
*   **Generates**:
    *   `pdf_SM_top.png`: Probability density functions comparing the distributions of DA vs OPL soil moisture.
    *   *(If activated in `lis.config`)*: Mean assimilation increment maps and innovation (`Observation - Background`) distribution histograms.

### 5. `validate_spatial.py`
Performs independent spatial validation against external satellite and reanalysis products (ASCAT, GRACE, GLEAM/MOD16).
*   **Generates**:
    *   `validation_grace_tws.png`: Terrestrial Water Storage Anomalies derived from summing the 4 SM layers + Canopy + SWE.
    *   `validation_ascat_sm.png`: Top layer soil moisture validation.
    *   `validation_et.png`: Evapotranspiration validation.

## How to Use

The entire framework can be executed locally or submitted as a batch job to the cluster.

To run the post-processing pipeline on the Toubkal cluster, submit the prepared SLURM job script from the **project root directory**:

```bash
sbatch scripts/jobs/job_postproc.sh
```

### Configuration Updates
When moving from the 3-day test run to the full multi-year spin-up, you must update the configuration block at the top of each Python script in `scripts/postproc/scripts/` to point to the correct output directories and date ranges:

```python
OPL_DIR = "experiments/multi_year/opl/output"
DA_DIR = "experiments/multi_year/assim_smap/output"
START_DATE = datetime(YEAR, MONTH, DAY)
END_DATE = datetime(YEAR, MONTH, DAY)
```
