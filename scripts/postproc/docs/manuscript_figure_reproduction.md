# Manuscript Figure Reproduction Guide (Hydrology)

## Overview
This document explains how to reproduce the core hydrological diagnostic figures for the SMAP Data Assimilation manuscript.

## Data Requirements
The figures rely on a pre-processed pixel-month parquet dataset generated by the ML pipeline.
- **Dataset Path**: `/home/mohammad.elaabaribao/lustre/empowermed-ahl6xm8o7mg/users/mohammad.elaabaribao/IA_SM_assim/data/processed/monthly_pixel_dataset_2016_2020_static.parquet`

## Generating the Hydrological Response Figures
To regenerate the spatial maps of the hydrological response (SSM, RZSM, ET, Runoff partitioning) and the CSV summaries, run the following script:
```bash
cd /home/mohammad.elaabaribao/lustre/empowermed-ahl6xm8o7mg/users/mohammad.elaabaribao/NoahMP_Morocco/scripts/postproc/
./scripts/run_manuscript_hydrological_response_figures.sh --overwrite
```
Outputs are written to `matrix_2016_2020/outputs/figures/hydrological_response/` and `matrix_2016_2020/outputs/figures/runoff_partitioning/`.
**Main Paper Figures**: `manuscript_hydro_response_states_ET_DJF_2016_2020.png`, `manuscript_hydro_response_states_ET_JJA_2016_2020.png`, `manuscript_runoff_partitioning_DJF_2016_2020.png`

## Generating the Flux-Only Water Balance
The water balance is automatically calculated and plotted by the same script (`run_manuscript_hydrological_response_figures.sh`).
Outputs are written to `matrix_2016_2020/outputs/figures/water_balance/`.
**Main Paper Figure**: `manuscript_flux_only_water_balance_2016_2020.png`

## Known Limitations
1. **No HyMAP Routing**: The runoff partitioning relies on pre-routing total runoff. The baseflow-like Qsb represents a deep slow buffer, not validated streamflow.
2. **Storage-Aware Water Balance**: The water balance is "flux-only". Temporal storage changes ($\Delta$S) are omitted due to temporal aggregation constraints, meaning it does not enforce strict mathematical closure.
